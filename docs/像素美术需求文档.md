# 2D 像素美术需求文档

## 1. 项目定位

当前运行资源统一存放于 `art/pixel/正式PNG/`；旧的 `原型PNG` 目录已移出项目。

本项目采用固定俯视角 2D 生存探索表现，整体方向为低饱和末日像素风，参考《星露谷物语》的清晰像素网格、《Darkwood》的压抑氛围以及《阿瑞斯病毒》的废墟探索结构。

第一阶段目标是建立可运行、可识别、可替换的原型美术资源；所有资源必须能够直接导入 Godot，并保持最近邻显示。

## 2. 统一规格

| 资源 | 规格 | 备注 |
|---|---:|---|
| 地图基础 Tile | 16×16 | 地面、道路、墙体和装饰使用整数网格 |
| 玩家 Sprite | 64×64 | 先做四方向基础帧，后续扩展八方向 |
| 普通敌人 Sprite | 48×48 | 深色轮廓，警戒状态使用红色提示 |
| 道具图标 | 32×32 | 透明背景，中心构图 |
| UI 图标 | 32×32 | 不使用模糊缩放 |
| 建筑组件 | 64×64 或 96×96 | 按 Tile 拼接，不绘制整张不可复用大图 |

## 3. 色彩规范

- 背景地面：灰绿 `#566457`、泥土 `#665846`、道路 `#3D3D3B`。
- 建筑废墟：冷灰 `#737675`、暗棕 `#4B3D35`、铁锈 `#8A4A3D`。
- 玩家：蓝灰 `#6D9AA3`，高光使用冷白。
- 敌人：近黑 `#171A1B`，受击使用浅红闪烁。
- 交互：暖黄 `#E4C45D`，警戒：橙红 `#D65A45`。
- 手电：暖白黄 `#FFE8A3`，只用于光源和重要反馈。

## 5. 动画要求

第一阶段只交付静态原型和单帧 SpriteSheet，确保逻辑先接入。第二阶段制作：

- 玩家待机、行走、奔跑、潜行、攻击和受伤。
- 敌人游荡、警戒、追击、攻击和死亡。
- 道具拾取闪烁、手电开关和交互提示。

## 6. Aseprite 工作规范

- 使用透明背景。
- 关闭抗锯齿，导出使用最近邻。
- 颜色限制在统一调色板内。
- 文件源格式保存为 `.aseprite`，运行资源导出为 `.png`。
- Godot 导入后关闭 Linear Filter，保持整数倍缩放。

## 7. 验收标准

- PNG 透明区域正确，无白底和灰边。
- 资源尺寸符合表格规格。
- 像素边缘清晰，没有半透明抗锯齿。
- 玩家、敌人和道具可以替换当前 `icon.svg` 临时贴图。
- 资源名称、目录和用途可以在代码层级索引中追踪。
