# 地图绘制工作包

## 素材

- 图集：`art/tilesets/末日基础图集_16x16.png`
- Tile 尺寸：`16×16`
- 当前 2D 相机缩放：`3`
- 推荐地图范围：`320×240` 世界单位

## Godot 操作顺序

1. 打开 `Project/主场景2D.tscn`。
2. 在 `World` 下创建多个 `TileMapLayer`：`地面层`、`道路层`、`建筑层`、`装饰层`。
3. 为 `地面层` 创建 TileSet，Tile 尺寸设置为 `16×16`。
4. 将 `末日基础图集_16x16.png` 拖入 TileSet 编辑器并创建全部图块。
5. 在地面层铺满草地，再用泥土和沙地绘制区域变化。
6. 在道路层绘制一条主路和四条支路，道路宽度建议为 `2-3` 个 Tile。
7. 在建筑层使用墙体、地板和废墟瓦片绘制房屋。
8. 在装饰层增加石块、草丛、木箱和废墟细节。

## 碰撞规则

- 草地、泥土、道路、木地板、沙地：不添加碰撞。
- 墙体、水面、废墟：添加碰撞。
- 房屋门口保留至少 `2` 个 Tile 宽度的入口。
- 碰撞只画在墙体实际占用区域，不要覆盖屋顶和门口。
- TileSet 物理层建议使用一个 2D 物理层，碰撞层设置为环境层 `4`。

## 推荐地图结构

```text
庇护所
  └─ 主路
	  ├─ 房屋搜索区
	  ├─ 第一基站
	  ├─ 第二基站
	  ├─ 第三基站
	  └─ 研究所最终区域
```

## 接入现有项目

绘制完成前保留 `主场景2D.gd` 的原型地图生成代码。完成 TileMap 后，再逐步停用 `_build_map()` 中的 Polygon2D、Line2D 和动态房屋，避免原型地图与正式地图重叠。
