# 代码分类索引

## 一、2D 游戏主线

| 文件 | 职责 |
|---|---|
| `主场景2D.gd` | 2D 世界初始化、地图装饰、道具、碰撞、掉落和 HUD 更新 |
| `玩家2D.gd` | 移动、奔跑、潜行、近战攻击和攻击射线 |
| `敌人2D.gd` | 2D 敌人状态机、移动、感知和受击接口 |
| `可交互道具2D.gd` | 道具显示、高亮、拾取和背包写入 |
| `可破坏物2D.gd` | 箱子生命值、受击、掉落生成和销毁 |
| `游戏状态.gd` | 自动加载的全局状态、背包、任务和存档 |
| `菜单.gd` | 菜单按钮、继续游戏、设置和音量 |
| `开场介绍.gd` | 剧情文本、跳过和进入主场景 |

### 2D 节点分类

| 分类 | 节点/脚本 | 主要职责 |
|---|---|---|
| 玩家系统 | `玩家2D`、`玩家2D.gd` | 角色移动、奔跑、潜行、鼠标方向近战攻击 |
| 敌人系统 | `敌人2D`、`敌人2D.gd` | 2D 敌人感知、游荡、追击、攻击和受击 |
| 道具系统 | `可交互道具2D`、`可交互道具2D.gd` | 道具显示、靠近高亮、拾取和背包写入 |
| 可破坏物系统 | `可破坏物2D`、`可破坏物2D.gd` | 生命值、受击、掉落和销毁 |
| 全局状态 | `GameState`、`游戏状态.gd` | 背包、任务、属性、位置和存档 |
| 2D 世界 | `主场景2D`、`主场景2D.gd` | 地图装饰、障碍、箱子、掉落和 HUD |
| 菜单流程 | `菜单`、`菜单.gd` | 新游戏、继续游戏、设置和退出 |
| 开场流程 | `开场介绍`、`开场介绍.gd` | 剧情文字、跳过和切换主场景 |

## 二、地图和 TileMap 工具

| 文件 | 职责 |
|---|---|
| `Script/MapGenerator.gd` | TileMap 图集、道路、建筑和废墟生成工具 |
| `Script/bake_map.gd` | 将生成地图烘焙到场景和 TileSet |
| `Script/verify_map.gd` | 检查地图节点、TileSet 和道具数量 |

## 三、已迁移的功能

项目已统一为 2D，不再保留 3D 场景和脚本。原 3D 版本中的功能对应关系如下：

| 原 3D 功能 | 当前 2D 实现 |
|---|---|
| 3D 玩家移动 | `玩家2D.gd` |
| 3D 敌人状态机 | `敌人2D.gd` |
| 3D 道具拾取 | `可交互道具2D.gd` |
| 3D 背包状态 | `游戏状态.gd` 的 `inventory` |
| 3D 电池/材料掉落 | `可破坏物2D.gd` 的掉落表 |
| 3D 场景流程 | `菜单.gd`、`开场介绍.gd`、`主场景2D.gd` |

## 四、注释规范

- 文件开头说明脚本职责和主要流程。
- 导出的参数用注释说明单位和用途。
- 复杂的运行时节点创建、碰撞分类和掉落规则保留短注释。
- 不为显而易见的赋值添加无意义注释。
