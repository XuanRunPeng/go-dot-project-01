# 项目状态

## 已完成

- 2D 菜单、开场介绍和主场景流程已接入。
- 2D 玩家支持 WASD 移动、奔跑、潜行、体力和存档位置恢复。
- 玩家初始拥有棒球棍，左键可朝鼠标方向进行近战攻击。
- 主场景不再生成测试怪物；敌人脚本仍保留正式生成接口。
- 2D 像素渲染已设置为最近邻过滤、无 Mipmap、整数窗口缩放和像素吸附。
- 角色 PNG 已接入主角精灵。
- 超市木头和箱子已按纹理尺寸创建碰撞体。
- 箱子具有 3 点生命值，破坏后会生成基础素材掉落。
- 食物和近战武器已放置在超市角落。
- 障碍使用 `obstacle_type` 分类，攻击使用射线检测遮挡。
- 远程仓库已绑定，当前分支已同步到远程最新提交。

## 进行中

- 新增掉落物目前没有独立像素图，缺失贴图时使用通用金色方块。
- 箱子掉落 ID 已接入背包数量系统，但食物恢复、材料合成等使用效果尚未完整实现。
- 敌人 AI 和攻击接口已存在，但当前主场景暂时关闭测试敌人生成。
