# 代码层级索引

本索引对应当前 Godot 项目。项目入口已经切换到 2D 版本；旧版 3D 文件保留在同一目录中，作为回退和功能参考。

## 一、项目入口

- `project.godot`
  - 配置运行分辨率、输入映射、主场景和全局单例。
- `Project/菜单.tscn`
  - 游戏启动菜单场景。
- `Project/菜单.gd`
  - 处理新游戏、继续游戏、设置和退出。
- `Project/开场介绍.tscn`
  - 黑屏剧情介绍场景。
- `Project/开场介绍.gd`
  - 以 5 个信息节点逐句淡入剧情文本，提供右上角跳过按钮，并切换到 2D 主场景。

## 二、2D 当前游戏主流程

- `Project/主场景2D.tscn`
  - 2D 场景节点、玩家、相机、HUD 和碰撞资源。
- `Project/主场景2D.gd`
  - 创建临时地图、生成道具和敌人、更新 HUD、处理附近交互，并承接开场黑场淡出。
- `Project/玩家2D.gd`
  - WASD 移动、Shift 奔跑、Ctrl 潜行、体力消耗和地图边界。
- `Project/敌人2D.gd`
  - 敌人游荡、警戒、追击和攻击状态机。
- `Project/可交互道具2D.gd`
  - 2D 贴图道具、靠近高亮、名称显示和 E 键拾取。

## 三、全局状态和数据

- `Project/游戏状态.gd`
  - Autoload 单例，管理任务、生命、体力、背包、装备、关键道具、基站和存档。
- `Project/道具数据库.json`
  - 道具名称、类别、类型和堆叠数据。
- `Project/背包道具.gd`
  - 背包道具按钮、整数数量显示和拖放数据。

## 四、旧版 3D 和功能参考

- `Project/主场景.tscn`、`Project/主场景.gd`
  - 旧版 3D 游戏主场景，当前不作为启动入口。
- `Project/玩家.gd`
  - 旧版 3D 玩家控制器。
- `Project/敌人.gd`
  - 旧版 3D 敌人控制器。
- `Project/可交互道具.gd`
  - 旧版 3D 道具交互。
- `Project/电池掉落.gd`
  - 旧版电池交互组件。
- `Project/图纸面板.gd`
  - 旧版建造图纸拖放面板。
- `Project/三维节点.tscn`
  - Godot 3D 节点测试场景。

## 五、资源和扩展

- `icon.svg`
  - 当前原型阶段通用临时贴图，后续替换为正式美术资源。
- `addons/godot-git-plugin/`
  - Git 插件，不属于游戏业务代码，保持原目录命名。

## 六、依赖关系

```text
菜单.tscn
  -> 菜单.gd
      -> 游戏状态.gd
      -> 开场介绍.tscn

开场介绍.tscn
  -> 开场介绍.gd
      -> 主场景2D.tscn

主场景2D.tscn
  -> 主场景2D.gd
      -> 玩家2D.gd
      -> 敌人2D.gd
      -> 可交互道具2D.gd
      -> 游戏状态.gd
```

## 七、命名约定

- 当前项目自有脚本、场景和数据文件使用中文名称。
- `2D` 和 `3D` 保留为技术后缀，用于区分同类实现。
- `addons`、引擎导入文件和第三方资源不重命名。
- 后续新增代码应先放入对应功能类别，再在本索引中登记。
